# 👟 ONE8 Shoes E-Commerce Database

## Overview

The **ONE8 Shoes E-Commerce Database** is a relational database designed to support an online shopping platform for the **ONE8 Shoes** brand. It provides a secure, scalable, and efficient database structure for managing customers, products, orders, payments, inventory, and administrative operations.

The database enables customers to register, log in, browse shoe collections, search products, add items to their shopping cart or wishlist, place orders, make secure payments, and track deliveries. Administrators can manage products, categories, inventory, customer accounts, orders, discounts, and sales reports efficiently through a well-structured database system.

---

## 🎯 Project Objectives

- Design a normalized relational database for an online shoe store.
- Provide secure customer registration and authentication.
- Manage products, categories, and brands efficiently.
- Support shopping cart and wishlist functionality.
- Process customer orders and payments securely.
- Maintain accurate inventory records.
- Generate sales and business reports.
- Ensure data integrity using database constraints and relationships.

## 🔗 Database Relationships

- One Customer can place multiple Orders.
- One Order contains multiple Order Items.
- One Product belongs to one Category.
- One Product belongs to one Brand.
- Customers can add multiple Products to their Shopping Cart.
- Customers can maintain multiple Wishlist items.
- Each Order has one Payment record.
- Each Order has one Delivery record.
- Products are linked with Inventory records.
- Customers can review purchased products.
